# 🏦 Sistema Bancário SQL

Projeto acadêmico desenvolvido em **SQL (Oracle Database)** com foco em **modelagem relacional de banco de dados**.

## 📌 Sobre o projeto
Este sistema simula a estrutura de uma instituição financeira, contendo:

- Cadastro de bancos
- Cadastro de agências
- Cadastro de contas correntes
- Relacionamento entre tabelas
- Inserção de dados para testes
- Consultas SQL

## 🛠 Tecnologias utilizadas
- SQL
- Oracle Database

## 📚 Conceitos aplicados
- DDL (Data Definition Language)
- DML (Data Manipulation Language)
- Primary Key
- Foreign Key
- Constraints
- Modelagem Relacional
- Integridade Referencial

## 🗂 Estrutura do Banco
O projeto possui 3 tabelas principais:

### BANCO
Armazena informações cadastrais das instituições financeiras.

### AGENCIA
Relaciona as agências pertencentes a cada banco.

### CONTA_CORRENTE
Armazena dados das contas correntes e seus respectivos correntistas.

## 🚀 Objetivo
Este projeto foi desenvolvido com o objetivo de praticar **criação de tabelas**, **relacionamentos**, **restrições de integridade** e **manipulação de dados em SQL**, fortalecendo conhecimentos em Banco de Dados para aplicação profissional na área de TI.
